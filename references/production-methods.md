# 原声溯源与自然咬字

“原声”必须标清是相机音轨直解码、剪后干声、已变速干声还是处理后混音，并记录文件SHA、采样率、转码/重采样、时间映射和已用DSP。代理画质降低不应带动音频降采样；ASR用16k音频不能进入成片处理链。输入从原始音轨解码为浮点，保音高变速尽量一次完成。局部增益（clip gain）是按短语/短窗口调音量，使弱字可听、突峰受控，不能把波形压成一条线；限制增益与变化斜率，检查字头、尾音和语气。降噪、去混响、动态分别做同句/同速/同响度比较。模型增强的电子感与咬字损伤优先于指标改善：可对齐延迟、匹配响度后少量混入自然分支，混合比例只属于本段试听结论。不得将示例项目的200ms、15%模型混合或目标LUFS变成全部录音默认。先核相位/延迟，再听小音量、辅音、尾声和最终AAC；没有可靠听辨则保留待作者试听。
